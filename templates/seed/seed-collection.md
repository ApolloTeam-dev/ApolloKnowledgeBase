# ApolloKnowledgeBase seed collection

Thanks for helping fill the knowledge base. This takes about 30–60 minutes.

**How it works**

1. Copy this file to `seed/<your-github-handle>.md` and fill it in.
2. Bullet points and rough notes are fine. Don't polish, don't worry about
   format. Just get the knowledge out of your head.
3. Submit it as a pull request.
4. An AI agent converts each entry into a proper knowledge base file as a
   `draft`, with you as owner.
5. You review those drafts. Only then do they become `reviewed`.

Skip any section where nothing comes to mind. Five good entries beat twenty
vague ones.
