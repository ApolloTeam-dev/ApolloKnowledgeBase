SAGA CONTROL Register



         +-------+----------+-------------------------------------------+
         | BIT#  | FUNCTION | DESCRIPTION                               |
         +-------+----------+-------------------------------------------+
         | 15    | SET/CLR            |                                |
         | 6     | FORCE OCS MODE     |                                |
         | 5     | Enable PAL ZOOM    |                                |
         | 4     | --                 |                                |
         | 3     | --                 |                                |
         | 2     | Enable Zoom        |                                |
         | 1     | Scanline Mode      |                                |
         | 0     | Scanlines On/Off   |                                |
         +-------+----------+-------------------------------------------+
Examples: No Zoom = apoke $DFF3EC 2 $0024
ZOOM1 (NTSC) = apoke $DFF3EC 2 $8004
ZOOM2 (NTSC+) = apoke $DFF3EC 2 $8020
ZOOM3 (PAL) = apoke $DFF3EC 2 $8024
