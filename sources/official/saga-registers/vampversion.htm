VAMP VERSION

         This register card version and CPU Clockrate


         +-------+----------+-------------------------------------------+
         | BIT#  | FUNCTION | DESCRIPTION                               |
         +-------+----------+-------------------------------------------+
         | 15-08 | Card    | Card Version                               |
         |       |         | 1=V600, 2=V500, 3=V4_500(Firebird=500/Salamander=2000/Phoenix=1000), 4=V4_1200(Icedrake), 5=V4SA, 6=V1200, 7=V4_600(Manticore)  |
         | 07-00 | Clock   | Clock multiplier                           |
         +-------+----------+-------------------------------------------+
