## Summary

The SAGA chunky plane is a linear framebuffer in any RAM. GFXMODE (`$DFF1F4`) selects resolution and pixel format, BPLHPT (`$DFF1EC`) points to the pixels and BPLHMOD (`$DFF1E6`) sets the row modulo.

## Details

### Registers

| Address | Name | Access | Description (original) |
|---|---|---|---|
| `$DFF1E6` | BPLHMOD | W | Chunky plane modulo |
| `$DFF1EC` | BPLHPTH | W | Chunky plane pointer (hi 16 bits) |
| `$DFF1EE` | BPLHPTL | W | Chunky plane pointer (lo 16 bits) |
| `$DFF1F4` | GFXMODE | W | Set Resolution and Pixformat |

- `$DFF1EC`: corrected: the high word of a 32-bit pointer has 16 bits.
- `$DFF1EE`: corrected: the low word of a 32-bit pointer has 16 bits.

### GFXMODE (`$DFF1F4`)

16bit register selecting the screen size and the pixelformat for the Chunky plane.

Bits 15–8 select the resolution, bits 7–0 the pixel format. Write it as one word: `(resolution << 8) | format`.

### Chunky plane pointer and modulo

- BPLHPTH/BPLHPTL (`$DFF1EC`): 32bit pointer to Chunky plane. The Chunky plane can show 8bit/16Bit/15bit/24bit/32bit screens.
- BPLHMOD (`$DFF1E6`): This is the number (sign extended) that is added to the UHRES bitplane pointer (BPLHPTL,H) every line, just like the other modulos. The original's text says "UHRES bitplane pointer"; on SAGA it is the chunky plane: the number of bytes skipped after each row (ApolloLib, SRC).

### Reading the current mode back

The original gives no read address. maggie.library's samples save the current mode and frame pointer from `$DFE1F4` and `$DFE1EC` (SRC, see [maggie-library.md](../../os/libraries/maggie-library.md)). Whether every SAGA register reads back at `$DFExxx` is an open question (see [index.md](index.md)).

## Differences from AmigaOS / AROS / 68060

- Classic Amiga chipsets have only planar bitplanes in Chip RAM. The chunky plane has 8- to 32-bit pixels and can be in Fast RAM.
- On ECS, `$DFF1E6`/`$DFF1EC` were BPLHMOD/BPLHPT for UHRES bitplanes; SAGA reuses the names for the chunky plane.

## Do / Don't

- DO write GFXMODE as one word, resolution in the high byte.
- DO set the pointer and modulo before you switch the mode.
- DON'T rely on GFXMODE `$00` or pixel format `$07`: the original describes neither.
