## Summary

SAGA sets 24-bit palette entries through 32-bit colour ports: one write gives the entry number and its red, green and blue. There is one port each for the planar, sprite, chunky and PIP palettes.

## Details

### Registers

| Address | Name | Access | Description (original) |
|---|---|---|---|
| `$DFF380` | PlanarCOLH | W | 32bit Planar COLOR Port register |
| `$DFF382` | PlanarCOLL | W | 256 Color Register, Format [ID,RR,GG,BB] |
| `$DFF384` | SpriteCOLH | W | 32bit Sprite COLOR Port register |
| `$DFF386` | SpriteCOLL | W | 256 Color Register, Format [ID,RR,GG,BB] |
| `$DFF388` | ChunkyCOLH | W | 32bit Chunky COLOR Port register |
| `$DFF38A` | ChunkyCOLL | W | 256 Color Register, Format [ID,RR,GG,BB] |
| `$DFF38C` | PIPCOLH | W | 32bit PIP COLOR Port register |
| `$DFF38E` | PIPCOLL | W | 256 Color Register, Format [ID,RR,GG,BB] |

Each port is one 32-bit register (the original lists its high and low word, H and L). A 32-bit write sets one entry of a 256-colour table:

| Bits | Function | Description |
|---|---|---|
| 31–24 | Number | 8bit Colornumber |
| 23–16 | RED | 8bit Red |
| 15–8 | GREEN | 8bit Green |
| 7–0 | BLUE | 8bit Blue |

| Port | Address | Table |
|---|---|---|
| Planar | `$DFF380` | Bitplane colours (256) |
| Sprite | `$DFF384` | Sprite colours (256) |
| Chunky | `$DFF388` | Chunky plane in 8-bit mode (256) |
| PIP 1 | `$DFF38C` | PIP 1 in 8-bit mode (256) |
| PIP 2 | `$DFF37C` | PIP 2 in 8-bit mode (256) (SRC, not in the original) |

### Example (original)

```asm
    move.l  #$00FF0000,$DFF380   ; colour 0 = red
    move.l  #$01FFFF00,$DFF380   ; colour 1 = yellow
```

### Copper: 32-bit MOVE

```asm
    dc.w    $8380,$00FF,$0000    ; colour 0 = red (original)
```

- The SAGA Copper can do 32-bit moves (G, 2026-11-04).
- A 32-bit MOVE has the high bit of its first word set (G, 2026-11-04): `$8380` = bit 15 + register `$380`. The two words after it are the 32-bit value, high word first, as in the original's example.
- It needs SAGA mode: set the SAGA bit in FMODE (`$DFF1FC` bit 4) first (G, 2026-11-04).
- Without the SAGA bit, the Copper is gated to `$DFF0xx` and `$DFF1xx` (G, 2026-11-04), so it can't reach the colour ports at `$DFF3xx`.
- With the SAGA bit set, the Copper can write every SAGA register, up to Arne at `$DFF4FF`, with 16-bit and 32-bit moves (G, 2026-11-04).

A classic Copper MOVE is two words (register, 16-bit value). Read the classic way, `$8380` would be COLOR00 (`$180`), and the third word the start of the next instruction.

## Differences from AmigaOS / AROS / 68060

- Classic COLORxx registers (`$DFF180`–`$DFF1BE`) hold 32 entries; AGA reaches 256 through banks and BPLCON3. A SAGA port writes any of 256 entries in one 32-bit write.

## Do / Don't

- DO write the port with one `move.l`.
- DO set FMODE bit 4 (SAGA) before a Copper list writes a colour port.
- DO set bit 15 in the first word of a 32-bit Copper MOVE.
