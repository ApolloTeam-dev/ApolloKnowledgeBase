## Summary

Arne, the SAGA audio unit, has 16 channels of 8- or 16-bit mono or 16-bit stereo samples from any RAM, each with a 32-bit pointer and length at `$DFF400 + n × $10`. Channels 0–3 are the Paula channels.

## Details

### Channel layout

16 channels, channel n at `$DFF400 + n × $10` (n = 0–15). The converter checks every row of the original against this layout.

| Offset | Register | Size | Access | Meaning |
|---|---|---|---|---|
| +0 | AUDxL | L | W | Pointer to the sample data (32-bit, any RAM) |
| +4 | AUDxLEN | L | W | Length in sample pairs (32-bit) |
| +8 | AUDxVOL | W | W | Volume: bits 15–8 left, 7–0 right |
| +A | AUDxCTRL | W | W | Control (see below) |
| +C | AUDxPER | W | W | Period (16-bit) |

- `$DFF430`: corrected: typo in the original: this is channel 3.
- `$DFF4A0`: corrected: typo in the original: the AUD10 block is at $DFF4A0, as the channel layout requires.
- `$DFF4CC`: corrected: typo in the original: AUD12PER is at $DFF4CC, as the channel layout requires.

### Channels 0–3 and Paula

Arne channels 0–3 are the four Paula channels: the same voices, with the classic registers at `$DFF0A0`–`$DFF0DF` and the Arne registers at `$DFF400`–`$DFF43F` (WDrijver, 2026-11-04). ApolloLib starts and stops channels 0–3 with DMACON bits 0–3 (`$DFF096`) and checks them in DMACONR (`$DFF002`); channels 4–15 use DMACON2 (SRC, see [arne-dma-and-interrupts.md](arne-dma-and-interrupts.md)).

### AUDxCTRL

| Bits | Function | Description |
|---|---|---|
| 2 | Stereo | 16bit/16bit interleaved mode - 64bit align |
| 1 | OneShot | Channel will turn itself off at sample end |
| 0 | 16bit | 0=8bit, 1=16bit samples |

Sample formats (original):

- 8bit signed mono. Data stored in pairs, data aligment 16bit
- 16bit signed mono, Data stored in pairs, data alignment 32bit
- Left/Rigth signed 16bit stereo, Data in memory in pairs, memory alignment 64bit

ApolloLib writes `$0005` (16-bit stereo, looping) and `$0007` (16-bit stereo, one-shot) (SRC). The other bits are not described.

### AUDxLEN

The count is in pairs of samples (original). For 16-bit stereo, ApolloLib writes the size in bytes / 8: one count is two stereo frames of 2 × 16 bits (SRC).

### AUDxVOL

Bits 15–8 left volume, bits 7–0 right volume (original). Each side ranges from `$00` to `$FF` (ApolloLib, SRC).

### AUDxPER

16bit PERIOD COUNT This register contains the period (rate) of audio channel x DMA data transfer. The minimum period is 65 color clocks. This means that the smallest number that should be placed in this register is 65 decimal. This corresponds to a maximum sample frequency of 56 khz.

The period coding is compatible with Paula: Arne runs at the same clock as Paula (G, 2026-11-04), the PAL colour clock of 3546895 Hz. So period = 3546895 / sample rate (44.1 kHz gives 80), and period 65 gives 3546895 / 65 = 54.6 kHz, not the 56 kHz in the original.

### Sample rate (G, 2026-11-04)

- Arne runs in a 60 kHz max mode (G, 2026-11-04): about 60 kHz is the highest rate; that is about period 59 (3546895 / 60000, calculated here).
- There is no minimum sample rate (G, 2026-11-04).
- The HDMI audio output resamples down, for compatibility with all monitors (G, 2026-11-04).
- For games, use 44.1 kHz (period 80), the CD standard (G, 2026-11-04).

## Differences from AmigaOS / AROS / 68060

- Paula has 4 channels, 8-bit samples, 6-bit volume and Chip RAM only. Arne channels 0–3 are those same channels, with the extra registers at `$DFF400`.
- Classic AUDxLEN counts words; Arne AUDxLEN counts sample pairs and is 32 bits.

## Do / Don't

- DO prefer the library calls (ApolloLib) to direct access to these registers: a best practice, not a forced rule (see [prefer-library-calls-for-saga-chips.md](../best-practices/prefer-library-calls-for-saga-chips.md)).
- DO use 44.1 kHz (period 80) for game audio (G).
- DO keep the period at 65 or higher, as the original says; above about 60 kHz nothing is gained (G).
- DO give AUDxLEN in sample pairs.
- DO start channels 0–3 with DMACON and channels 4–15 with DMACON2.
- DON'T program channel 0–3 through both register sets at the same time.
