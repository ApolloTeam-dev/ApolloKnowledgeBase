## Summary

SAGA reads USB joypads (`$DFF220`–`$DFF226`) and the USB mouse wheel (`$DFF212`) through registers, and adds the DB9 ports at `$DFF20A`/`$DFF20C`.

## Details

### Registers

| Address | Name | Access | Description (original) |
|---|---|---|---|
| `$DFF20A` | JOY0DAT | R | Vanilla DB9 Joystick-mouse 0 data (vert, horiz) |
| `$DFF20C` | JOY1DAT | R | Vanilla DB9 Joystick-mouse 1 data (vert, horiz) |
| `$DFF212` | Mouse Wheel | R | Mouse Wheel read register |
| `$DFF220` | joy0buttons | R | 16bit USB Joy Buttons (0)=active |
| `$DFF222` | joy1buttons | R | 16bit USB Joy Buttons (0)=active |
| `$DFF224` | joy2buttons | R | 16bit USB Joy Buttons (0)=active |
| `$DFF226` | joy3buttons | R | 16bit USB Joy Buttons (0)=active |

- `$DFF20A`: a SAGA address; the original also marks OCS, ECS and AGA.
- `$DFF20C`: corrected: typo in the original.
- `$DFF20C`: a SAGA address; the original also marks OCS, ECS and AGA.

### USB joypads (`$DFF220`–`$DFF226`)

One register per joypad. The index describes them as "16bit USB Joy Buttons (0)=active"; ApolloLib reads a set bit as pressed and bit 0 as connected (SRC). ApolloLib's names are in the last column.

| Bits | Function | Description | ApolloLib |
|---|---|---|---|
| 15 | Right | Move RIGHT |  |
| 14 | Left | Move Left |  |
| 13 | Down | Move Down |  |
| 12 | Up | Move Up |  |
| 11 | Reserved |  |  |
| 10 | Start | Start |  |
| 09 | Back | Back |  |
| 08 | FIRE8 | Firebutton 8 | TR |
| 07 | FIRE7 | Firebutton 7 | TL |
| 06 | FIRE6 | Firebutton 6 | BR |
| 05 | FIRE5 | Firebutton 5 | BL |
| 04 | FIRE4 | Firebutton 4 | Y |
| 03 | FIRE3 | Firebutton 3 | X |
| 02 | FIRE2 | Firebutton 2 | B |
| 01 | FIRE1 | Firebutton 1 | A |
| 00 | PLUG | Joypad connected | Connected |

ApolloLib also reads bits 2/3 as right stick X and bits 1/4 as right stick Y (SRC).

### Mouse wheel (`$DFF212`)

| Bits | Use |
|---|---|
| 15–10 | unused |
| 9 | Mouse Button 5 |
| 8 | Mouse Button 4 |
| 7–0 | signed 8 bit counter counts USB mouse Wheel events |

### DB9 joysticks (`$DFF20A`, `$DFF20C`)

The "vanilla" DB9 ports, with the layout of JOY0DAT/JOY1DAT. The original's index marks them OCS, ECS and AGA too, but these addresses are SAGA's.

### Extra fire buttons in POTGO (classic register)

- Bit 14 = Firebutton 2 Joy2
- Bit 12 = Firebutton 3 Joy2
- Bit 10 = Firebutton 2
- Bit  8 = Firebutton 3

## Differences from AmigaOS / AROS / 68060

- Classic Amiga input is JOYxDAT, POTGO/POTINP and CIA bits, without USB, wheel or more than 3 buttons.

## Do / Don't

- DO test bit 0 (connected) before you trust a joypad register.
- DO treat the wheel counter as signed and use the difference between two reads.
