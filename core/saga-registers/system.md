## Summary

`$DFF3FC` gives the V4 board ID and the CPU clock multiplier. Core revision, chip ID and SPI registers sit at `$DFF3EA`–`$DFF3FA`.

## Details

### Registers

| Address | Name | Access | Description (original) |
|---|---|---|---|
| `$DFF3EA` | CORE REVISION | R | Reserved |
| `$DFF3F0` | CHIP ID | R | – |
| `$DFF3F2` | CHIP ID | R | – |
| `$DFF3F4` | CHIP ID | R | – |
| `$DFF3F6` | CHIP ID | R | – |
| `$DFF3F8` | SPI WRITE | R | Reserved |
| `$DFF3FA` | SPI read | R | Reserved |
| `$DFF3FC` | VAMPIRE VERSION | R | 8bit Card Version / 8bit clock multiplier |

### VAMPIRE VERSION / board ID (`$DFF3FC`)

Bits 15–8: board (card) ID. Bits 7–0: CPU clock multiplier.

| ID | Board | Source |
|---|---|---|
| $01 | V2-V600 (legacy) | ApolloOS |
| $02 | V2-V500 (legacy) | ApolloOS |
| $03 | V4 Firebird (A500); also Salamander (Firebird on an A2000 adapter) and Phoenix (Firebird on an A1000 adapter) | WDrijver, original |
| $04 | V4 IceDrake (A1200) | WDrijver, original |
| $05 | V4 Standalone | WDrijver, original |
| $06 | V2-V1200 (legacy) | ApolloOS |
| $07 | V4 Manticore (A600) | WDrijver, original |
| $08 | V4 UniCorn (A6000) | WDrijver, ApolloOS |

The original's list says 1 = V600, 2 = V500, 6 = V1200 without "V2", and lacks `$08`. ApolloOS marks `$09` as future.

All V4 boards run the same core: the board ID tells the board, not different SAGA features (see [hardware/index.md](../../hardware/index.md)).

### Other registers

CORE REVISION, CHIP ID and the SPI registers have no description in the original. SPI WRITE (`$DFF3F8`) is marked R there, which is unlikely for a write register.

## Differences from AmigaOS / AROS / 68060

- Classic Amiga chipsets have DENISEID (`$DFF07C`) for the video chip only; there is no board or clock register.

## Do / Don't

- DO read the board ID with `move.w $DFF3FC` and use the high byte.
- DON'T use the board ID to decide which SAGA features exist: they are the same on every V4 board with the same core.
